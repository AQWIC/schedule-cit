# График работы сотрудников ЦИТ (УО «ВГТУ»)

Веб-приложение для составления, ведения и печати еженедельного графика работы сотрудников Центра информационных технологий (ЦИТ) Витебского государственного технологического университета.

## Основные возможности

1. **Интерактивная таблица графика:**
   - Редактирование времени и статусов («Больничный», «Вых», «Отгул») прямо в ячейках таблицы.
   - **Автозаполнение растягиванием (как в Excel):** выделение ячейки и протяжка значения в любую сторону (влево, вправо, вверх, вниз).
   - Быстрый поиск сотрудников по Ф.И.О. в реальном времени.

2. **Понедельный учёт:**
   - Компактный переключатель недель (`<< [ ДД.ММ.ГГГГ - ДД.ММ.ГГГГ ] >>`) с возможностью возврата к текущей неделе в один клик.
   - **Автоматический перенос графика:** при переходе на новую неделю график смен и список сотрудников переносятся с прошлой недели.

3. **Учёт отгулов:**
   - Автоматическое начисление (`+1`) за работу в выходные дни (суббота, воскресенье).
   - Автоматическое списание (`-1`) при установке статуса «Отгул» в будние дни.
   - Сквозной перенос накопленного баланса отгулов между неделями (включая работу «в долг»).

4. **Управление сотрудниками:**
   - Добавление новых сотрудников через модальное окно с валидацией и автоматической очисткой Ф.И.О. от лишних пробелов.
   - Удаление сотрудников из графика.

5. **Печатная форма А4 (альбомная ориентация):**
   - Вызов окна печати с выбором даты подписания документа.
